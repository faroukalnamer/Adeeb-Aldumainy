# أديب الدُميني — Phone Care | تطبيق ويب متكامل

تطبيق ويب تقدمي (PWA) متكامل وشامل لخدمات، تتبع، وإدارة صيانة وبرمجة الهواتف الذكية لمركز **م. أديب الدُميني** في اليمن (دمنة خدير — شارع النيابة سابقاً).

---

## 🌟 الميزات والأنظمة المدمجة في تطبيق الويب

### 1. 🔍 نظام تتبع حالة الصيانة اللحظي (Live Repair Tracker)
- استعلام مباشر برقم تذكرة الصيانة الفريد (مثل `AD-7091`) أو برقم هاتف العميل.
- شريط زمني تفاعلي من 5 مراحل مع مؤشرات ضوئية نابضة:
  1. تم استلام الهاتف
  2. الفحص والتشخيص الفني المجهري
  3. قيد الصيانة واستبدال القطع
  4. اختبار الجودة والضمان
  5. جاهز للاستلام والتسليم
- عرض الفني المسؤول (م. أديب الدُميني)، القطع الأصلية المستبدلة، التكلفة، ومدة الضمان.
- زر تواصل مباشر عبر واتساب برابط يرسل تفاصيل التذكرة بدقة للفني.
- نماذج تجريبية سريعة بنقرة واحدة لتجربة مختلف الحالات.

### 2. ⚡ حاسبة وتشخيص الأعطال الفورية (Interactive Cost Estimator)
- محاكي ثلاثي الأبعاد لاختيار الشركة (Apple, Samsung, Xiaomi, Huawei, Infinix, Pixel).
- تحديد نوع العطل (شاشة، بطارية، آي سي شحن، ماء، رومات، فك شفرات، تخطي حماية).
- تحديد فئة القطعة (وكالة أصلية 100% أو درجة أولى High Copy).
- حساب فوري لمتوسط التكلفة التقديرية (بالدولار والريال اليمني)، والوقت المقدر والضمان.
- زر لتحويل بيانات الفحص مباشرة إلى نموذج حجز الصيانة.

### 3. 📅 نظام حجز الصيانة والاستلام الإلكتروني (Online Booking & Intake)
- نموذج تفاعلي لتسجيل بيانات العميل، نوع الجهاز، ووصف المشكلة.
- خيارات التسليم (تسليم مباشر بالمركز أو طلب مندوب استلام وتوصيل).
- توليد تذكرة صيانة رسمية بكود فريد تلقائياً (`AD-XXXX`) وحفظها في قاعدة البيانات.
- ميثاق لحماية خصوصية وسرية بيانات العميل وصوره.
- تأكيد الطلب فورا برسالة واتساب جاهزة ومنسقة.

### 4. 🛠️ لوحة تحكم الفني وإدارة المركز (Technician & Admin Hub)
- مؤشرات أداء حية (KPIs): إجمالي التذاكر، قيد الفحص، قيد الصيانة، الجاهزة، والإيرادات.
- جدول تفاعلي لإدارة التذاكر مع فلترة سريعة وتغيير الحالة لحظياً.
- إمكانية فتح تذكرة استلام جديدة يدوياً للزبائن داخل المحل.
- تعديل التكلفة والملاحظات الفنية للتقرير الهندسي.
- تصدير واستيراد قاعدة بيانات التذاكر كملف JSON.

### 5. 🖨️ محرك طباعة الإيصالات والضمان (Print Engine)
- بطاقة استلام وفاتورة وضمان رسمي مطابقة للمعايير المعتمدة.
- باركود محاكى للتتبع، تفاصيل العطل، القطع، والتكلفة، وشروط الضمان.
- دعم الطباعة المباشرة أو التصدير كـ PDF عبر تنسيق `@media print`.

### 6. 🚨 دليل طوارئ وإسعافات الأجهزة (Emergency Device First-Aid)
- إرشادات فورية لحالات سقوط الهاتف في الماء، التوقف على الشعار، انتفاخ البطارية، والشاشة السوداء مع ما يجب وما يُحظر فعله قطعا.

### 7. 📲 تطبيق ويب تقدمي (PWA Ready)
- قابل للتثبيت على الهواتف الذكية والحواسب (Installable PWA).
- يعمل في وضع عدم الاتصال (Offline) بفضل Service Worker والتخزين المحلي.

## 🚀 طريقة التشغيل

### تشغيل خادم التطبيق المحلي:

```bash
npm run dev
# أو
node server.js
```

افتح المتصفح على:
```
http://localhost:3000
```

### لبناء نسخة الإنتاج (Production Build):

```bash
npm run build
```
سيتم إنشاء المجلد `dist/` جاهزاً للنشر على أي منصة استضافة (Vercel, Netlify, Render, VPS...).

## 🏗️ هيكلية المشروع

```text
├── index.html            # الواجهة التفاعلية لتطبيق الويب (Semantic Arabic RTL SPA)
├── styles.css            # نظام التصميم المرئي الحديث (Cyber-Tech Dark UI)
├── app.js                # المحرك التفاعلي، إدارة الحالة، والمزامنة
├── server.js             # خادم Node.js مع واجهة REST API كاملة
├── sw.js                 # Service Worker للتخزين المؤقت والعمل أوفلاين
├── package.json          # أوامر التشغيل والبناء
├── data/
│   ├── tickets.json      # قاعدة بيانات تذاكر الصيانة
│   └── services.json     # كتالوج الخدمات والأسعار
└── public/
    ├── manifest.json     # ملف تعريف تطبيق الويب PWA
    ├── icon-192.png      # أيقونة PWA 192x192
    ├── icon-512.png      # أيقونة PWA 512x512
    └── favicon.ico       # أيقونة المتصفح
```
